# 大肥鱼3D记忆脑

把她的记忆画成一颗**真实皮层脑**（MRI 模型），外加一条从出生到今天的时间线。

## 页面

- 中央：皮层脑，点节点看连线与相关记忆
- 左：活跃/归档数量、节点类型图例、四激素进度条
- 右：标准（人格锚点）/ 回溯 / 评估 / 技术
- 底部：暂停流动 / 转动视角 / 重置视角 / 显示隐藏

## 时间线

按年份排开她的一生（2004 → 现在），点开看当时的配图与"当时在聊什么"。
数据来自旧库 episodes + 新库 memories，自动去重、自动挂图。

## 依赖数据

- `brain.db`（脑图）
- `dafeiyu_brain/memory.db`（时间线的真实日期）
- AstrBot 主库（聊天图片）

## 命令

`/脑3d` 手动刷新。

## 注意

直链 token 7 天过期，建议从「面板 → 插件」进入。

## 常见问题

**页面只有光环和光束，没有大脑**

说明半球模型文件没装上。完整的 `pages/panel/cortex/` 需要这几个文件：

```
lh.bin  rh.bin                       各约 5 MB
lh.hologram.bin  rh.hologram.bin     各约 2.5 MB
lh.fibers.bin    rh.fibers.bin       各约 220 KB
```

安装包约 7.7 MB。如果你拿到的包只有 2–3 MB，说明是被精简过的，
要找完整版重装——页面没有模型文件时不会报错，只是画不出脑形。
